# Astroloh - Профессиональный навык Астролог для Яндекс Алисы

Голосовой навык для Яндекс Алисы с профессиональными астрологическими расчетами на базе библиотеки Kerykeion и интеграцией ИИ.

## 🚀 Полная интеграция Kerykeion (2025-08-09)

**Astroloh теперь полностью интегрирован с библиотекой Kerykeion 4.x для профессиональных астрологических расчетов!**

## ⏰ Централизованная обработка времени (2025-08-10)

**Astroloh использует централизованную систему обработки времени через `astro_time_utils.py`:**

### 🔧 Ключевые функции времени
- **`utcnow()`** - Замена `datetime.utcnow()` с timezone-aware объектами
- **`now(tz)`** - Текущее время в указанном часовом поясе
- **`current_timestamp()`** - ISO timestamp строка для API
- **`db_timestamp_default()`** - Фабрика для SQLAlchemy defaults
- **`create_astro_datetime()`** - Создание AstroDateTime объектов

### 🌍 Поддержка российских часовых поясов
- **60+ российских городов** с автоматическим определением часового пояса
- **Локализация**: "Москва" → "Europe/Moscow", "Новосибирск" → "Asia/Novosibirsk"
- **Координаты городов** для точных астрологических расчетов
- **DST обработка** и переходы на летнее/зимнее время

### 🔒 Безопасность и производительность
- **Валидация входных данных** с защитой от инъекций
- **LRU кэширование** часовых поясов (256 записей)
- **Immutable объекты** AstroDateTime для thread-safety
- **Мониторинг производительности** и логирование ошибок

### ⭐ Новые возможности Kerykeion
- **🏗️ Расширенные системы домов**: Placidus, Koch, Equal, Whole Sign, Regiomontanus, Campanus, Topocentric, Alcabitus, Morinus, Porphyrius, Vehlow, Meridian, Azimuthal, Polich Page, Natural Graduation
- **🪐 Полный набор небесных тел**: Солнце, Луна, планеты + Хирон, Лилит, Церера, Паллада, Юнона, Веста
- **🎯 Профессиональные аспекты**: Мажорные и минорные аспекты с точными орбисами и цветовым кодированием
- **📊 Арабские части**: Расширенный набор - Фортуна, Дух, Любовь, Брак, Карьера с формулами расчета
- **🔄 Вторичные прогрессии**: Развитие личности по дню = году

- **🎨 SVG-генерация карт**: Профессиональные астрологические карты

## Технологический стек

- **Backend**: Python 3.12, FastAPI
- **База данных**: PostgreSQL
- **Кэширование**: Redis 5.0.1 с асинхронной поддержкой
- **Мониторинг**: psutil для системных метрик
- **Астрологические вычисления (Multi-Backend)**: 
  - 🥇 **Kerykeion 4.x** (основная библиотека для профессиональной астрологии)
  - 🥈 **Swiss Ephemeris** (pyswisseph) - высокоточные эфемериды (резерв)
  - 🥉 **Skyfield** - астрономические расчеты на Python (резерв)
  - 🔧 **Встроенные методы** - базовые вычисления (резерв)
- **Интеграция**: Яндекс.Диалоги API
- **ИИ-генерация**: Yandex GPT для персонализированных гороскопов
- **Безопасность**: Шифрование персональных данных
- **Производительность**: Асинхронная обработка, пулы потоков, умное кэширование
- **Инфраструктура**: Docker, CI/CD

## Быстрый старт

### С Docker

1. Склонируйте репозиторий:

```bash
git clone https://github.com/evgenygurin/astroloh.git
cd astroloh
```

2. Скопируйте и настройте переменные окружения:

```bash
cp .env.example .env
# Отредактируйте .env файл с вашими настройками
```

3. Запустите с Docker Compose:

```bash
docker-compose up --build
```

4. Откройте <http://localhost:8000/docs> для просмотра API документации

### Локальная разработка

1. Создайте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. Установите зависимости:

**Для Linux/Windows (полная установка с компиляцией):**

```bash
pip install -e ".[full,dev]"
```

**Для macOS (без компиляции C-библиотек):**

```bash
pip install -e ".[macos,dev]"
```

**Минимальная установка:**

```bash
pip install -e ".[minimal,dev]"
```

**Для совместимости с существующими скриптами:**

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Астрологические библиотеки

Проект поддерживает несколько астрологических библиотек с автоматическим переключением и приоритетом:

1. **Kerykeion** >=4.11.0 - ⭐ **ОСНОВНАЯ** библиотека для профессиональной астрологии
   - Полные натальные карты с всеми планетами (включая Хирон, Лилит, Лунные узлы)
   - Аспекты с цветовым кодированием и настраиваемыми орбисами
   - Множественные системы домов (Placidus, Koch, Equal, Whole Sign и др.)
   - Поддержка тропического и сидерического зодиака
   - Синастрия (совместимость карт)
   - Транзиты и прогрессии
   - SVG-генерация астрологических карт
   - Арабские части (жребии)

2. **Swiss Ephemeris** (pyswisseph) - высокоточные астрономические вычисления (фолбэк)
3. **Skyfield** - астрономические расчеты на чистом Python (фолбэк)
4. **Astropy** - профессиональная астрономическая библиотека (фолбэк)

**Рекомендации по установке:**

- **Linux/Windows**: используйте полную установку `[full]` для всех возможностей
- **macOS**: используйте `[macos]` - Kerykeion совместим без компиляции C
- **Professional**: используйте `[professional]` для максимальной астрологической точности
- **CI/Docker**: используйте `[minimal]` для базовых функций
- **Разработка**: всегда добавляйте `[dev]` для инструментов разработки

**Система приоритетов**: Kerykeion → Swiss Ephemeris → Skyfield → Встроенные алгоритмы

### Производительность и кэширование

Для оптимальной производительности рекомендуется настроить Redis:

```bash
# Установка Redis (Ubuntu/Debian)
sudo apt-get install redis-server

# Настройка в .env файле
REDIS_URL=redis://localhost:6379/0
```

**Системные требования**:
- **Минимум RAM**: 512MB (рекомендуется 1GB)
- **Redis память**: 64-128MB для типичного использования
- **Фоновый CPU**: Резервировать 10-20% для мониторинга

**Метрики производительности**:
- Система автоматически отслеживает время отклика
- Встроенные алерты для медленных операций
- Статистика попаданий в кэш в реальном времени
